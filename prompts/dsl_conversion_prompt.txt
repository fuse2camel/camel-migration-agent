CONVERSION PATTERNS:

Route Definition:
XML: <route id="myRoute"><from uri="direct:start"/></route>
Java: from("direct:start").routeId("myRoute")

Choice/When/Otherwise:
XML: <choice><when><simple>${body} == 'test'</simple>...
Java: choice().when(simple("${body} == 'test'"))...

Split:
XML: <split><simple>${body}</simple>...
Java: split(body())...

Process:
XML: <process ref="myProcessor"/>
Java: process(exchange -> { /* logic */ }) or .bean(MyProcessor.class)
